RUN IN VS CODE
1. Extract this ZIP file.
2. Open Visual Studio Code.
3. Select File > Open Folder and choose megasri_portfolio.
4. Open index.html.
5. Right-click and choose Open with Live Server (install the Live Server extension first).

PERSONALIZE
- Your supplied portrait and two supplied certificates are already included.
- Review all project descriptions and education details before publishing.
- In script.js, replace your-professional-email@example.com with a professional email
  only if you want to make that address public.
- The contact form opens the visitor's email application. It does not send or store
  messages on a website server.

PUBLISH WITH GITHUB PAGES
1. Create a GitHub repository.
2. Upload all project files and the assets folder.
3. Open repository Settings > Pages.
4. Select Deploy from a branch, choose main and /(root), then save.
5. Wait for GitHub Pages to provide the website URL.

PRIVACY
The project does not display your phone number or home address. Check all public
information before publishing your portfolio.


PORTFOLIO CHAT ASSISTANT
A floating chat widget is included. It answers a set of common questions about
the portfolio and guides visitors to the LinkedIn and GitHub links.
Important: this starter chatbot uses predefined JavaScript responses. It is not
connected to a real AI model or backend. A real AI chatbot requires a secure
backend/API integration; never put a private API key directly in browser JavaScript.


CERTIFICATE DISPLAY
Each certificate card shows a short description first. The certificate image is
hidden when the page loads. Click “View Certificate” to display it, then click
“Hide Certificate” to hide it again.
